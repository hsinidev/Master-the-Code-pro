## 📖 Deep-Dive Technical Documentation

# 42 Mastery Suite - Ultimate Computer Science Training Platform


**42 Mastery Suite** is a premier, gamified educational platform engineered to bridge the gap between theoretical computer science concepts and practical application. Inspired by the rigorous peer-to-peer curriculum of the **42 Network**, this suite offers 14 distinct interactive modules.

## 📂 Project Structure

```bash
42-mastery-suite/
├── public/              # Static assets (robots.txt, sitemap.xml, favicon)
├── src/
│   ├── assets/          # Shared game assets (SVG paths, colors)
│   ├── components/      # Reusable UI components (Grid, Palette, Modals)
│   ├── gameLogic/       # Core engines for algorithms (Graph, DP, Bash)
│   ├── modes/           # Individual Game Mode Components (14 Modules)
│   ├── services/        # Level data generators and logic helpers
│   ├── types/           # TypeScript interfaces and Enum definitions
│   ├── App.tsx          # Main Application Entry & Routing
│   └── index.tsx        # React DOM rendering
├── package.json         # Dependencies and scripts
└── README.md            # Documentation
```

## ✨ Features Overview

### 🧠 Core Algorithmic Training
*   **Algorithmic Path:** Master recursion and stack-based execution logic.
*   **Sorting Wars:** Visualize Bubble, Insertion, and Selection sorts.
*   **Graph Theory Quest:** Interactive DFS, BFS, and Dijkstra's algorithm.
*   **Dynamic Grid:** Learn Dynamic Programming (DP) through grid optimization.

### 🌐 Systems & Networking
*   **NetConfig 42:** Simulate IP addressing, Subnetting (CIDR), and Routing.
*   **ShellScript Scramble:** A fully functional Bash terminal simulation.
*   **Pipeline Flow:** Visualize asynchronous data streams and buffer management.
*   **Deadlock Manager:** Understand thread synchronization and mutex locks.

### 📐 Logic & Mathematics
*   **Number Theory Cipher:** Cryptography, Primes, and Modular Arithmetic.
*   **DataStruct Duel:** Time Complexity (Big O) analysis.
*   **Boolean Builder:** Logic gates and circuit design.
*   **Zebra Deduction:** Constraint satisfaction puzzles.

## 🛠️ Technology Stack

*   **Frontend Framework:** React 18 (Hooks, Functional Components)
*   **Language:** TypeScript (Strict Typing)
*   **Styling:** Tailwind CSS (Responsive, Glassmorphism)
*   **State Management:** React Context & Local State
*   **SEO:** JSON-LD Schema, Semantic HTML5

## 📦 Installation & Setup

1.  **Clone the repository**
    ```bash
    git clone https://github.com/hsinidev/42-mastery-suite.git
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run development server**
    ```bash
    npm start
    ```

4.  **Build for production**
    ```bash
    npm run build
    ```
